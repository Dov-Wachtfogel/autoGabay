## תכונות

- **חלוקה הוגנת:** מסך התלמידים מציג את כולם לפי ניקוד מצטבר, מהנמוך לגבוה.
- **ניהול תלמידים:** הוספה, שינוי שם והסרה של תלמידים.
- **ניהול תורנויות:** תפילות יומיות, תפילות שבת וחג, ראש חודש וקריאות תורה קצרות וארוכות.
- **תפילות מותאמות:** הוספת תפילות נוספות, שינוי ניקוד ברירת המחדל והסתרת תורנויות שאינן בשימוש.
- **היסטוריית רישומים:** הזנה, עריכה והסרה של רישום לתלמיד; ההיסטוריה נשמרת גם כאשר תורנות מוסתרת.
- **ייצוא ושחזור CSV:** ייצוא סיכום לפי טווח תאריכים, יצירת גיבוי מלא ושחזור נתונים מקובץ גיבוי.
- **ממשק בעברית:** תמיכה בכיווניות RTL, מצב כהה ומצב בהיר.

## התחלה מהירה

### דרישות

- Android Studio
- Android SDK Platform 37
- JDK 17 ומעלה
- מכשיר או אמולטור עם Android 13 (API 33) ומעלה

### פתיחה והרצה

1. משכפלים את המאגר ופותחים את התיקייה ב-Android Studio.
2. ממתינים לסיום Gradle Sync.
3. בוחרים מכשיר או אמולטור ולוחצים **Run**.

אפשר גם לבנות משורת הפקודה:

```bash
./gradlew :app:assembleDebug
```

להרצת בדיקות יחידה:

```bash
./gradlew :app:testDebugUnitTest
```

## גיבוי ושחזור

באפליקציה יש שני סוגי ייצוא:

- **ייצוא סיכום** — טבלת CSV עם סיכום התלמידים והרישומים בטווח התאריכים שנבחר.
- **גיבוי CSV מלא** — כולל תלמידים, סוגי תורנויות, ניקוד ברירת מחדל ורישומים, לרבות תאריכים והערות.

לשחזור בוחרים **שחזור מקובץ CSV** ומאשרים את הקובץ. השחזור ממזג נתונים לפי מזהים, ולכן ניתן לייבא שוב אותו גיבוי בלי לשכפל רישומים קיימים. מומלץ לשמור עותק גיבוי מחוץ למכשיר.

## מבנה הפרויקט

```
app/src/main/
├── java/com/example/autogabay/
│   ├── MainActivity.kt              # ממשק, מסכים וזרימות משתמש
│   ├── Models.kt                    # תלמידים, רישומים וסוגי תורנות
│   ├── assignments.kt               # מאגר, ViewModel ומצב המסך
│   ├── SqliteStudentRepository.kt   # אחסון מקומי ב-SQLite
│   ├── StudentCsvBackup.kt         # ייצוא ושחזור גיבוי CSV
│   └── StudentCsvExporter.kt       # ייצוא טבלת הסיכום
└── res/
    └── drawable/yeshiva_logo.png
```

**טכנולוגיות:** Kotlin · Android SDK · AndroidX ViewModel · Coroutines ו-Flow · SQLite · Material Components
